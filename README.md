# ORBIT OS

A futuristic browser-based simulated desktop operating system built using pure HTML, CSS, and JavaScript.

## Features

- Boot screen
- Lock screen with PIN authentication
- Desktop environment
- Taskbar
- Digital clock
- File Manager
- Folder navigation
- Breadcrumb navigation
- Search
- File sorting
- Back and forward navigation
- File selection
- Right-click context menu
- Draggable windows
- Minimize and maximize windows

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
